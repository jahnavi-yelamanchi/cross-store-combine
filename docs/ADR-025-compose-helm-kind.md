# ADR-025: Compose for local parity, Helm for EKS/AKS, kind for cluster tests

- Context: the code runs on in-process fakes (moto, mongomock, InProcessBus); the CDC path (Postgres/Mongo -> Debezium -> Kafka API + Schema Registry), Dagster, Langfuse and Prometheus/Grafana need real services locally, and the same image must ship to EKS and AKS.
- Decision: one multi-stage `Dockerfile` (uv, non-root, `runtime` and `dagster` targets); `deploy/compose/compose.yaml` with profiles `core` (postgres wal_level=logical, mongo rs0, Redpanda, Debezium Connect + `connect-init`, dynamodb-local, MinIO), `app` (proposals API, CRM stub, Dagster) and `observability` (Langfuse, Prometheus, Grafana); Helm chart `deploy/helm/xstore` with `values-eks.yaml` (IRSA) and `values-aks.yaml` (Entra workload identity); `deploy/kind` for local cluster runs. Redpanda replaces Kafka + ZooKeeper locally and serves the Schema Registry under the `schema-registry` alias the connector configs already use.
- Alternative rejected: Kafka + ZooKeeper + Confluent Schema Registry in Compose (three JVMs, slower start, no gain for a Kafka-API client); raw manifests or Kustomize per cloud (identity wiring, HPA/PDB and ServiceMonitor toggles would be duplicated).
- Why: Compose gives one-command parity on a laptop; Helm values isolate the only cloud differences (registry, identity annotations/labels, env); kind exercises the chart against a real API server without a cloud account.
- Consequence: the chart never renders a Secret (`secrets.existingSecret`, enforced when STORE_BACKEND is not local) and mounts `policy/policy.yaml` and `stores/mappings` via chart symlinks; the API defaults to per-pod SQLite with 1 replica, as no Postgres driver is locked yet; the Debezium image lacks the Confluent Avro converter, so its jars go in `deploy/compose/connect-plugins/`; Compose mounts `observability/` and runs `xstore.orchestration.definitions`, which land in parallel PRs. Validation here is `helm lint`/`helm template` and `docker compose config` only; kubeconform is not run.
